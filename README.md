# Universal Translator

কপি → শর্টকাট → অনুবাদ → কপি → পেস্ট। কোনো API key লাগে না।
Tauri 2 + React + TypeScript + Rust, Windows 10/11 x64।

## ইনস্টলার বানানো (টার্মিনাল ছাড়া)
1. GitHub রিপোজিটরির সব পুরোনো ফাইল মুছে এই ফোল্ডারের সব ফাইল আপলোড করুন (`.github` ফোল্ডারসহ)।
2. Actions ট্যাব → "Build Windows installer" → Run workflow।
3. বিল্ড শেষ হলে (১০–১৫ মিনিট) artifact **UniversalTranslator-Windows-x64** নামান, ভেতরের `.exe` চালান।
4. নতুন ভার্সন ইনস্টলের আগে ট্রে আইকনে রাইট-ক্লিক করে পুরোনো অ্যাপ **Quit** করুন।

## ব্যবহার
কোনো অ্যাপে লেখা সিলেক্ট করে `Ctrl+C` দিন, তারপর:

| শর্টকাট | কাজ |
|---|---|
| Ctrl+Shift+T | অ্যাপ খোলে, ক্লিপবোর্ডের লেখা বসায় ও অনুবাদ করে |
| Ctrl+Shift+B | ক্লিপবোর্ডের লেখা বাংলায় অনুবাদ |
| Ctrl+Shift+E | ক্লিপবোর্ডের লেখা ইংরেজিতে অনুবাদ |
| Ctrl+Shift+L | টার্গেট ভাষা বাছাইয়ের তালিকা খোলে |
| Ctrl+Shift+C | অনুবাদ কপি করে |

শর্টকাট বদলাতে ⚙ Settings → Global shortcuts-এ বক্সে ক্লিক করে নতুন কী চাপুন।
নিচের বারে Mini / Expand দিয়ে মোড বদলান। ✕ চাপলে অ্যাপ ট্রে-তে লুকায়, বন্ধ করতে ট্রে আইকন → Quit।

## অনুবাদ কীভাবে হয়
- প্রথমে Google-এর পাবলিক ফ্রি এন্ডপয়েন্ট, ব্যর্থ হলে MyMemory (বেনামে দিনে প্রায় ৫,০০০ অক্ষর)।
- লেখা তখনই বাইরে যায় যখন আপনি অনুবাদ চান। ব্যাকগ্রাউন্ডে কিছু পাঠানো হয় না।
- Google-এর এই এন্ডপয়েন্ট অফিসিয়াল API নয়, তাই ভবিষ্যতে বন্ধ বা সীমিত হতে পারে।
- বড় লেখা নিজে থেকে ছোট টুকরোয় ভাগ হয়, লাইন ও প্যারাগ্রাফ ঠিক থাকে।

## জানা সীমাবদ্ধতা
- Listen বাটন Windows-এ ইনস্টল করা ভয়েস ব্যবহার করে। বাংলা ভয়েস না থাকলে Settings → Time & language → Speech থেকে যোগ করুন।
- কোনো শর্টকাট অন্য প্রোগ্রাম নিয়ে রাখলে নিচের বারে ⚠ সতর্কতা আসবে, Settings থেকে বদলে নিন।
- Voice-to-text এই ভার্সনে নেই।
